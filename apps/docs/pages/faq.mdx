# FAQ

## What is GenUI Protocol?

It is a compact AST-based protocol for representing AI-generated interfaces in a framework-agnostic way.

## Can I render the same AST in multiple frameworks?

Yes. The runtime and renderer adapters make it possible to render the same AST in multiple environments.

## Is the protocol safe?

Yes. It avoids arbitrary code generation and encourages declarative component metadata.
