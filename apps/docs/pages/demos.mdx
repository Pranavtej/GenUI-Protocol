# Demos

Short recordings of the real apps in this repository. Each shows a document being rendered and updated; none are mock-ups. They are regenerated by `scripts/demo/record-demos.cjs`.

## Edit JSON, watch charts and graphs re-render

The playground: the JSON is the whole UI. Change a chart's `type` from `bar` to `line` to `pie`, change a value in the data model, introduce a mistake and see the validator's message, then open an execution-graph example.

## Cards and forms that talk to an agent

## Record your own

```bash
pnpm build
(cd examples/react-app && npx vite preview --port 4175) &
(cd apps/playground && npx vite preview --port 4173) &
(cd apps/playground-angular/dist/playground-angular/browser && python3 -m http.server 4303) &
NODE_PATH=$(npm root -g) node scripts/demo/record-demos.cjs             # all
NODE_PATH=$(npm root -g) node scripts/demo/record-demos.cjs charts json  # some
```

Needs Playwright with Chromium and `ffmpeg`.
