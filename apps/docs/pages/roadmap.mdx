# Roadmap

- Phase 1: AST, runtime core, React renderer, MCP discovery
- Phase 2: Angular, Vue, Svelte, richer component metadata
- Phase 3: streaming updates, real-time dashboards, AI copilots
- Phase 4: React Native, Flutter, SwiftUI support
- Phase 5: open governance and protocol standardization
