# Contributing

```bash
pnpm install
pnpm build
pnpm lint
pnpm test
```

Python parts (`packages/sdk/python`, `apps/python-test`) need Python 3.10+: `pip install -e ".[dev]" && pytest`.

## Ground rules

- **The spec and conformance fixtures are the contract.** A protocol change updates `spec/SPEC.md`, the schemas in `packages/core/schemas`, the fixtures in `conformance/`, and both the TypeScript and Python implementations.
- **Generated files are not edited by hand:** `spec/schemas/*` (`pnpm --filter @genui-protocol/schemas emit`), the Python `registry.json` (`pnpm emit:registry`), and the generated docs pages. Tests fail if they drift.
- **Add tests with your change.** Compiled output (`*.js`, `*.d.ts`, `dist/`) is never committed.
- **Releases** use [changesets](https://github.com/changesets/changesets): run `pnpm changeset` and describe the change for each package you touched.

See the repository's [CONTRIBUTING.md](https://github.com/Pranavtej/GenUI-Protocol/blob/main/CONTRIBUTING.md) and [CODE_OF_CONDUCT.md](https://github.com/Pranavtej/GenUI-Protocol/blob/main/CODE_OF_CONDUCT.md).

## Dependency updates

Dependabot's weekly minor/patch updates are approved and auto-merged once CI is green; major updates get a `needs-review` label and are never auto-merged. See `.github/workflows/dependabot-auto-merge.yml` for the policy and the repository settings it needs.
