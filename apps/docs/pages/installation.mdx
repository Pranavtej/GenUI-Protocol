# Installation

## Requirements

- Node.js 18 or newer, pnpm 8 or newer
- Python 3.10+ for the Python SDK and the sample agent

## From the repository (current)

```bash
git clone https://github.com/Pranavtej/GenUI-Protocol.git
cd GenUI-Protocol && pnpm install && pnpm build
pnpm test            # runs every package's tests
```

## Packages

Release automation is set up (changesets, npm provenance), but **nothing has been published yet**. Names below are what will be published.

| Package | Purpose |
|---|---|
| `@genui-protocol/protocol`, `ast` | Types, actions, stream frames, shared constants |
| `@genui-protocol/runtime-core` | Tree, id-keyed diff, RFC 6902 patches, data store, actions, `RuntimeSession` |
| `@genui-protocol/validation` | Document validator with limits, URL checks, allow-lists |
| `@genui-protocol/stream-engine` | Ordered stream consumer with resync, SSE client |
| `@genui-protocol/component-registry` | Component metadata and props schemas |
| `@genui-protocol/renderer-react` | React renderer |
| `@genui-protocol/angular` | Angular renderer (reference implementation) |
| `@genui-protocol/theme-engine` | Design tokens → CSS variables |
| `@genui-protocol/sdk-js` | Typed builders, MCP client |
| `@genui-protocol/prompt-kit` | System prompt and tool definitions for LLMs |
| `@genui-protocol/cli` | The `genui` command |
| `@genui-protocol/eval` | `genui-eval`, a validity benchmark for models |
| `genui_protocol_sdk` (PyPI) | Python SDK |

## Python SDK

```bash
pip install -e packages/sdk/python      # from the repository
```

## MCP server

```bash
node apps/mcp-server/dist/index.js --http    # REST + SSE on 127.0.0.1:4000
```

See [MCP server](/mcp-server) for configuration and Docker.
