# Tutorials

## Build a simple dashboard

1. Create an AST with a page and KPI cards.
2. Normalize it with the runtime helper.
3. Reconcile it against the previous tree for incremental updates.

## Extend the protocol

Use the schemas and component-registry packages to add new primitives and renderer metadata.

## Contribute to docs

Keep docs concise, link to source material, and preserve technical meaning while improving clarity.
