# Features

GenUI Protocol is designed for AI-generated interfaces that need to remain portable, compact, and interactive.

## Core capabilities

- Compact AST payloads optimized for LLM output
- Multi-framework rendering without code generation
- Validation and reconciliation in a runtime engine
- Structured event routing and reactive state reduction
- Incremental patch delivery for streaming UIs

## Supported surfaces

- React
- Angular
- Vue
- Svelte
- React Native
- SwiftUI
- Flutter

## Why it matters

The protocol keeps the interface declarative while letting each renderer adapt the presentation layer for the target platform.
