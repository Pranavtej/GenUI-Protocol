# Getting started

This takes about five minutes and ends with a document rendered, edited and validated.

## 1. Get the code

The packages are not on npm yet, so work from the repository:

```bash
git clone https://github.com/Pranavtej/GenUI-Protocol.git
cd GenUI-Protocol
pnpm install
pnpm build
```

Requires Node 18+ and pnpm 8+.

## 2. See it run

```bash
pnpm --filter genui-protocol-example-react dev   # http://localhost:4175
```

Pick **Access request workflow**, fill the form and press *Request access*. The submit action sends an event to a scripted agent, which answers with data patches; the workflow advances. Open **Agent run monitor** and press *Play stream* to watch sequenced frames arrive.

The playground (`pnpm --filter genui-protocol-playground dev`) lets you edit a document and see validation errors as you type.

## 3. Render your own document

```tsx
import { GenUiRenderer, createSession } from "@genui-protocol/renderer-react";

const document = {
  version: "1.0.0",
  data: { count: 3 },
  root: {
    t: "card",
    p: { title: "Cart" },
    c: [
      { t: "text", p: { content: { $tpl: "Items in cart: {{count}}" } } },
      { t: "button", p: { label: "Set to 4", onClick: { do: "setData", path: "count", value: 4 } } },
    ],
  },
};

const session = createSession({ document, onEmit: (event) => console.log("to agent:", event) });

export const App = () => <GenUiRenderer session={session} theme="light" />;
```

The *session* owns the tree and the data. Renderers subscribe to it; actions and streamed frames go through it.

## 4. Validate before you render

```ts
import { validateDocument } from "@genui-protocol/validation";

const result = validateDocument(document);
if (!result.valid) console.error(result.errors);
```

Or from a shell: `genui validate doc.json` (exit code 1 and a readable list when invalid).
