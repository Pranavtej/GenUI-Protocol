## The pieces you will use most

| You want to… | Use |
|---|---|
| Build a document | `ui.*`, `bind`, `tpl`, `actions`, `document` from `@genui-protocol/sdk-js` (Python: `genui_protocol_sdk`) |
| Validate | `validateDocument`, `createValidator({ registry, limits, allowedComponents })` |
| Hold state and run actions | `createSession({ document, onEmit, onNavigate, allowedActions })` |
| Apply updates | `session.applyFrame(frame)`, `applyPatches(node, patches)`, `diffRuntimeTree(a, b)` |
| Consume a stream | `new StreamConsumer({ apply, onResync })`, `connectSSE(url, onFrame)` |
| Render | `<GenUiRenderer session theme components />` (React), `<genui-session-host>` (Angular) |
| Theme | `createTheme`, `themeToCssVars`, `autoThemeCss` |
| Prompt a model | `buildSystemPrompt`, `toAnthropicTools`, `toOpenAITools` |
