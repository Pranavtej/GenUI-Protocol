# Changelog

Per-package changelogs are generated by changesets at release time (`CHANGELOG.md` in each package). This page summarises what has landed since the project began.

## Unreleased (0.2.0)

- **Protocol v1 draft:** specification, published JSON Schemas, conformance fixtures.
- **Runtime:** id-keyed diff, full RFC 6902 patches, hardened validator, data store, actions, `RuntimeSession`, ordered stream consumer.
- **Interactivity:** `$bind` / `$tpl`, two-way inputs, `setData` / `toggle` / `navigate` / `emit` / `submit`.
- **Renderers:** real React renderer; Angular gains bindings, actions and seven more components.
- **Tooling:** hardened MCP server, prompt kit, JS and Python SDKs, `genui` CLI, `genui-eval`, registry UI.
- **Docs and examples:** this site, three runnable examples, a demo.
- **Breaking vs. the unreleased 0.1.x code:** npm scope is `@genui-protocol/*` (was `@ainative-ui/*`); Angular `Guip*` components are `GenUi*`; `validateASTDocument` is deprecated in favour of `validateDocument` / `validateNode`.
