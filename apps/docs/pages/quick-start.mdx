# Quick start

## Build a document in code

```ts
import { ui, bind, tpl, actions, document, assertValid } from "@genui-protocol/sdk-js";

const doc = document(
  ui.page({ title: tpl("Hello {{user}}") },
    ui.kpi({ label: "Revenue", value: bind("metrics.revenue"), trend: "up", trendValue: "+8%" }),
    ui.button({ label: "Refresh", onClick: actions.emit("refresh") }),
  ),
  { user: "Ada", metrics: { revenue: "$94,201" } },
);

assertValid(doc); // throws listing every problem
```

```python
from genui_protocol_sdk import ui, bind, actions, document, assert_valid

doc = document(
    ui.page(ui.kpi(label="Revenue", value=bind("metrics.revenue")),
            ui.button(label="Refresh", on_click=actions.emit("refresh")), title="Overview"),
    data={"metrics": {"revenue": "$94,201"}},
)
assert_valid(doc)
```

## Render in React

```tsx
const session = createSession({ document: doc, onEmit: (e) => agent.send(e) });
<GenUiRenderer session={session} />;
```

## Render in Angular

```ts
// app.config.ts
providers: [provideGenUiRenderer(), provideGenUiTheme()]
```

```html
<!-- renders a document with its own session; emit/submit actions come out as events -->
<genui-session-host [document]="doc" (agentEvent)="onAgentEvent($event)" />
```

## From the command line

```bash
genui scaffold form > form.json
genui validate form.json
genui diff before.json after.json > patches.json
genui prompt                         # system prompt for your LLM
```
