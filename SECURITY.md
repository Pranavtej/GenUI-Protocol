# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within GenUI Protocol, please send an
email to security@genui-protocol.dev. All security vulnerabilities will be
promptly addressed.

Please do not report security vulnerabilities through public GitHub issues.
