# @genui-protocol/eval

Measures how reliably an LLM emits valid GenUI documents: first-try validity, repair rate, feature coverage and size vs rendered HTML

Part of [GenUI Protocol](https://github.com/Pranavtej/GenUI-Protocol) — let AI agents answer with interfaces, not just text.
