# Mascot options

**Chosen: C · Builder** (the final assets are in the parent folder, built by `scripts/mascot/mascot.py`). The other options are kept here in case you want to switch later. Source: `scripts/mascot/opt_*.py`; open [`preview.html`](preview.html) for light/dark and small-size previews.


| | |
|---|---|
| **A · Curly** — a smiley held in curly braces `{ ☻ }` that pops UI widgets out of its head | ![A](a-curly-256.gif) |
| **B · Morph** — a jelly blob that becomes what the document says: card → button → checkbox | ![B](b-morph-256.gif) |
| **C · Builder** — a robot that catches UI blocks and stacks them into a dashboard | ![C](c-builder-256.gif) |
| **D · Sprout** — a tree-spirit that is an AST: it grows nodes and the leaves become widgets | ![D](d-sprout-256.gif) |
